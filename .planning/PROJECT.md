# Nexora

## Purpose
A cozy Roblox-inspired virtual library where students can focus, read, and study together online.

## Core Identity
- **Visual Style:** Warm 3D game world (large bookshelves, wooden study tables, chairs, soft lamps, plants, block-style avatar characters).
- **Vibe:** Calm, friendly, polished, suitable for students.
- **Originality:** Inspired by social game worlds, but completely original (no Roblox branding or assets).

## Long-term Vision
Full-fledged virtual study world with real user accounts, group rooms, chat, voice/video calls, achievements, custom avatars, and a mobile application.
